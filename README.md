# Taió Plumbing System — Hub

Página inicial que reúne as 4 aplicações web do projeto (Mestrado em
Geologia, UFSC — sistema intrusivo de Taió):

- [taio-plumbing-system-3d](https://github.com/Thubaraleii/taio-plumbing-system-3d) — modelo 3D interativo
- [taio-plumbing-system-2d](https://github.com/Thubaraleii/taio-plumbing-system-2d) — seção transversal interativa
- [TAIO-DASH](https://github.com/Thubaraleii/TAIO-DASH) — dashboard geoquímico
- [TAIO-WEBMAP](https://github.com/Thubaraleii/TAIO-WEBMAP) — webmap em tela cheia

Abra `index.html` direto no navegador, ou acesse a versão publicada
(GitHub Pages) deste repositório.
